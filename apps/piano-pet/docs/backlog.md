## 開発順序（推奨）

```
Epic 1（基盤）
  → Epic 2（データ層）
    → Epic 3（猫SVG）+ Epic 4（ホーム画面）  ← 並行可
      → Epic 5（練習記録）
        → Epic 6（履歴）+ Epic 7（ショップ）  ← 並行可
          → Epic 8（サウンド）
            → Epic 9（バッジ）
```

## MVP 完了条件

以下がすべて動作すること：

- [ ] きーちゃん（子猫）がホームに表示される
- [ ] 練習を記録するとコイン・XPが加算される
- [ ] 10回以上でボーナスが入る
- [ ] 連続練習日数が表示される
- [ ] レベルアップで猫の見た目が変わる
- [ ] ショップでアイテムを買って装備できる
- [ ] Androidのホーム画面に追加できる（PWA）
