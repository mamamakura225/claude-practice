# ピアノペット 要件定義書

> **何を・誰のために作るか（WHAT）の正本**。ふるまい・数値・実装は [features.md](./features.md)、データ構造と同期は [data-model.md](./data-model.md)、書き方と更新ルールは [README.md](./README.md)。

## 1. 概要・目的

5歳の子どものピアノ練習を**習慣化**するための PWA。親が練習を記録し、猫の育成・きせかえ・えさやり・バッジ・スタンプちょうで続ける動機をつくる。

## 2. 利用者と前提

| 項目 | 内容 |
|---|---|
| 親 | 練習の記録・修正、せってい（親ゲートの内側） |
| 子ども（5歳） | 猫の成長・きせかえ・バッジ・スタンプを親と一緒に見る。スタンプを押す・アイコンを選ぶのは本人 |
| 端末 | スマートフォン中心（ホーム画面に追加する PWA）。認証なし |
| 記録の単位 | 1回 ＝ 1曲を1回弾く |
| 1日の目標 | 既定10回。親が 5〜20 で調整できる（#238） |
| コインの達成ボーナス | 目標設定に依らず **10回で固定**（#238） |

## 4. 非機能要件

### 4.1 データと同期

| 区分 | 要件 |
|---|---|
| 保存 | localStorage が主。Firestore へ同期して複数端末で共有する。スキーマはバージョン管理する |
| 起動速度（#142） | localStorage を同期で読んでホームを即描画し、クラウド同期はアイドルまで遅らせる。初回の取り込みはローカル優先でマージする |
| オフライン（PWA） | オフライン動作・ホーム画面追加に対応。クラウドSDKは動的読み込みで、取れなくてもローカルだけで起動する |

### 4.2 セキュリティとプライバシー

| 区分 | 要件 |
|---|---|
| 計測 | Sentry・PostHog は鍵が無ければ無効。送るのは操作の種類と頻度だけで、**曲名・こども名・ごほうびの文字・レッスン日などの内容は送らない** |
| クラウド保存先の保護（#233 段階1） | doc ID を推測できなくする。匿名認証＋セキュリティルールは段階2（#258・→ [data-model.md 7章](./data-model.md#7-がぞくコードdoc-id-の推測不能化233-段階1)） |

#### 受容しているリスク（#258）

- 段階1が塞ぐのは「推測して**到達**される」ことだけ。doc ID を知られたときの**改ざん・破壊は防げない**（認証が無い）。家庭内ツールとして段階2まで受容する
- そのかわり state を信頼せず、次の2つを必須とする
  1. **壊れたデータを渡されても起動不能にならない**（`normalizeState` の型矯正・#272）
  2. **innerHTML へ載せる前に必ずエスケープする**（[js/html.js](../js/html.js) `escapeHtml`・#274）

### 4.3 体験と品質

| 区分 | 要件 |
|---|---|
| 表記（#359） | 子どもが読む表示は**ひらがな主体**。漢字はカレンダーの曜日と日付の「年月日」（親向け）だけ。語の途中で改行しない |
| 見やすさ | 文字は背景に対して AA のコントラスト（#359）。子どもが触るボタンは 44px 以上（#397） |
| アクセシビリティ（#151） | `prefers-reduced-motion` で飾りの動きを止める。ダークモード（じどう／あかるい／よる） |
| 軽量性（#147 #284） | 配信時に最小化し（#430）、その HTML/CSS/JS の gzip サイズに**予算**を設け、CI で超過を落とす。厳しい上限は起動をブロックする JS に掛け、押されるまで要らない機能は動的 import にする（→ [features.md](./features.md#アセット総量とパフォーマンス予算)） |
| 品質保証 | 純粋ロジックは Vitest、主要フローは Playwright。CI 通過後に Vercel へデプロイ |

## 5. スコープ外（現状）

- 複数の子どものプロフィール／認証／ユーザー間共有
- 練習曲の動画検索（YouTube API）、天気連動ボーナス（Open-Meteo API）
- 練習リマインダー通知（PWA Push）
- 猫の画風の切り替え（リアル系／ほわほわ系／ドット絵）。※毛色の3スタイル（#66）は実装済み

今後の拡張は [GitHub Issues](https://github.com/mamamakura225/claude-practice/issues)（`app/piano-pet` ラベル）で管理する。
