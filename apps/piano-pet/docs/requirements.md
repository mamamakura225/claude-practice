# ピアノペット 要件定義書

## 概要

5歳の子供のピアノ練習を習慣化するためのPWAアプリ。
親が練習記録を入力し、子供と一緒に結果を見て楽しむ。
猫キャラクターの育成・アイテム収集によるゲーミフィケーションで練習を継続させる。

---

## ユーザー

| ユーザー | 役割 |
|----------|------|
| 親 | 練習記録の入力 |
| 子供（5歳） | 猫の成長・アイテムを親と一緒に確認・楽しむ |

---

## 練習の記録単位

- **1回** = 1曲（または曲の一部）を1回弾くこと
- **1日の目標** = 10回以上
- 記録例：「きらきら星 × 5回、ちょうちょ × 5回」= 合計10回
- 記録は親がアプリに入力する

---

## 画面構成

### 画面1：ホーム

子供と一緒に見るメイン画面。

**表示要素**
- 猫のSVGイラスト（大きく・中央に表示）
- 猫の名前
- レベル・経験値バー（XPバー）
  - 経験値が溜まると猫がレベルアップ
  - 「あと○回でレベルアップ」が視覚的にわかる
- 所持コイン数
- ストリーク（連続練習日数）+ 炎アイコン
- 「練習を記録する」ボタン（親が押す）
- ナビゲーション：ホーム / 記録履歴 / ショップ

**猫のアニメーション**
- 通常：ゆっくり呼吸・尻尾を振る
- 練習記録直後：ぴょんと跳ねる、ハートが飛ぶ
- 2日以上練習なし：眠っているポーズ

### 画面2：練習記録入力（親操作）

**入力項目**
- 日付（デフォルト：今日）
- 曲の記録（複数追加可能）
  - 曲名（テキスト入力）
  - 回数（数値入力）
- 「記録する」ボタン

**記録後の動作**
1. コイン・経験値を計算して加算
2. ホーム画面に遷移
3. 猫が喜ぶアニメーション再生
4. 獲得コイン数をポップアップ表示

### 画面3：記録履歴

過去の練習記録を一覧表示。

**表示内容**
- 日付・曲名・回数のリスト
- 週ごとの合計回数グラフ（棒グラフ）
- 連続練習記録（ストリーク）の履歴

### 画面4：ショップ

猫のアイテムをコインで購入する画面。

**アイテム一覧（初期）**

| アイテム名 | 種類 | 価格 |
|-----------|------|------|
| 赤いリボン | 首アクセサリー | 50コイン |
| 麦わら帽子 | 頭 | 80コイン |
| 星の首輪 | 首アクセサリー | 100コイン |
| ミニマント | 背中 | 150コイン |
| 王冠 | 頭 | 300コイン |

- 購入済みアイテムは「装備する」ボタンに変わる
- 装備するとホームの猫SVGに重ねて表示

## ゲーミフィケーション設計

### コイン獲得

| 条件 | 獲得コイン |
|------|-----------|
| 1回練習（1曲1回） | 1コイン |
| 目標達成（10回以上） | +5コイン（ボーナス） |
| ストリーク3日 | +10コイン |
| ストリーク7日 | +30コイン |

### 経験値（XP）とレベルアップ

| 条件 | 獲得XP |
|------|--------|
| 1回練習 | 1XP |
| 目標達成（10回以上） | +3XP（ボーナス） |

**レベルと必要XP（例）**

| レベル | 必要累計XP |
|--------|-----------|
| 1 | 0 |
| 2 | 20 |
| 3 | 50 |
| 4 | 90 |
| 5 | 140 |
| 6〜 | 前レベルから+60ずつ増加 |

### 猫の成長段階

| レベル | 見た目 |
|--------|--------|
| 1〜5 | 子猫（小さい・丸い） |
| 6〜15 | 若猫（少し大きく・スリム） |
| 16〜 | 大人の猫（どっしり・風格あり） |

### バッジ（実績）

| バッジ名 | 条件 |
|---------|------|
| はじめての練習 | 初回記録 |
| 10回チャレンジ | 累計100回達成 |
| れんぞく3日 | 3日連続練習 |
| れんぞく7日 | 7日連続練習 |
| 1ヶ月がんばった | 30日以上練習記録あり |

## 技術スタック

| 項目 | 技術 |
|------|------|
| フロント | Vanilla JS（HTML/CSS/JS） |
| スタイリング | CSS（アニメーション含む） |
| 猫イラスト | SVG（リアル寄りスタイル） |
| データ保存 | LocalStorage |
| PWA対応 | manifest.json + Service Worker |
| サウンド | Web Audio API（効果音） |
| グラフ | Canvas APIまたはSVG（外部ライブラリなし） |
