# ピアノペット 要件定義書

> **何を・誰のために作るか（WHAT）**を記述する。画面・報酬の具体仕様は [features.md](./features.md)、データ構造・同期は [data-model.md](./data-model.md) が正本。
> **更新ルール**: `apps/piano-pet/` のソースを変更したら関連docsへ必ず反映する（[CLAUDE.md](../../../CLAUDE.md)）。

## 1. 概要・目的

5歳の子供のピアノ練習を**習慣化**するためのPWAアプリ。親が練習記録を入力し、子供と一緒に結果を見て楽しむ。猫キャラクターの育成・きせかえ・えさやり・バッジ収集によるゲーミフィケーションで継続を促す。

## 2. ターゲットユーザー・利用形態

| 項目 | 内容 |
|---|---|
| 親 | 練習記録の入力・編集を行う |
| 子供（5歳） | 猫の成長・なでなで・きせかえ・バッジを親と一緒に確認して楽しむ |
| 端末 | スマートフォン中心（PWAでホーム画面に追加）。認証なし |
| 記録単位 | 「1回 = 1曲を1回弾く」。**1日の目標は既定10回**（親ゲート内で 5〜20 に調整可・#238）。ごほうびコインの達成ボーナスは目標設定に依らず**10回で固定** |

## 3. 機能要件

要件レベルの一覧。各機能の詳細仕様・数値・コード参照は [features.md](./features.md)。

| 機能 | Issue | 要件 |
|---|---|---|
| 初回オンボーディング | #141 | 猫の吹き出し3画面の紙芝居で「①記録 → ②ごほうび → ③きせかえ・ごはん」を案内し初期離脱を防ぐ。スキップ可・一度見たら出さない。新規アセットを持たない軽量実装 |
| ホーム | #167 | 猫の表示（なつき度tier×mood）、今日の目標進捗、レベル/XP・コイン・連続日数・お休み券・なかよし度 |
| 練習記録 | #117 / #123 / #164 / #186 | 2方式を切替。**スタンプモード**＝曲の選定は親・回数のスタンプ（🐾）は子。**まとめモード**＝押せなかった日を後から曲×回数で入力。記録でコイン・XP・ストリーク・バッジを更新。スタンプは当日中カードを引き継ぐ（日付が変われば破棄） |
| 曲の色 | #122 / #165 | 曲名を決定的ハッシュで色に割り当てスタンプ・チップに反映（保存不要・どの端末でも同じ色）。色がかぶる場合は隣の色へずらす |
| 記録履歴 | #145 / #236 | 一覧・週次グラフ・月間ヒートマップ・連続記録の確認、編集と削除（後は整合を保つよう再計算）。**曲別コレクション**（曲ごとの累計回数）。各記録に**はなまるスタンプ**（💮/🌟/👍）と**練習の質メモ**（#239・🐢/🎵/🚀）をワンタップ付与（自由記述は持たず絵文字のみ） |
| ショップ | #124 / #126 / #226 / #270 | コインの使い道は「きせかえアイテムの購入・装備」と「えさやり（なかよし度上昇）」。きせかえは猫に**着せる装着アイテム**に加え、猫の前後シーンに**置く置物・小物**もあり、どちらもドラッグ／ピンチで自由配置でき、**アイテムごとに猫の「まえ／うしろ」を選べる**（#270）。なかよし度のしきい値で**なかよしレベル**が上がりご褒美が解放される（解放状態はなかよし度から導出） |
| バッジ | — | 練習の積み重ねで実績を獲得・一覧表示 |
| ふりかえり | #144 | きろく画面で今週の練習量（かいすう／きょく数／日数）を1枚のカードに集約。**先生への共有ボタンは #261 で削除**（先生はアプリの利用者として登場しない方針・#152） |
| 写真モード | #237 | 飾った猫を1枚の画像にして共有／保存。端末内完結（サーバ不要）、共有ペイロードに曲名・こども名を含めない |
| 育成・報酬 | #148 / #167 | 練習回数に応じたコイン/XP、レベルアップ、なかよし度による猫の表情・ポーズ変化、連続練習の維持（お休み券による救済）、練習した日だけ低確率でもらえる「きょうのおまけ」 |
| こどものアバター | #121 | ヘッダ隅にこども本人のアイコン（絵文字）と名前を常設し「自分が主役」の自己効力感を持たせる。タップで選択（こども本人の操作なので親ゲートなし）。**顔写真は不採用**（認証なしの共有 Firestore に置くためプライバシー上不可）＝絵文字選択方式とし、名前・アイコンは analytics に送らない |
| 猫とのインタラクション | #187 | なでると鳴く・反応する（記録には影響しない） |
| サウンド | #139 | 効果音・鳴き声。ON/OFF切替可。スタンプは押すたびにドレミ…と音程が上がり、目標マスで高いド（オクターブ）に解決する（ドレミの音程感覚を養う） |
| せってい：バックアップ/復元 | #140 | 認証なし・匿名同期のため、親が全データを JSON へ書き出し／読み込みできる。読み込みは上書き確認＋直前データの自動退避付き |
| せってい：データ初期化 | #183 | 機種変更前・配布前に、テストで汚れたデータを新品に戻す。確認ダイアログ＋自動退避を経てローカル・クラウド両方を初期化 |
| せってい：アカウント分離 | #182 | 検証・テスト目的で複数アカウント（既定：娘／テスト用）を切替。認証は導入せず、保存先の Firestore ドキュメント／localStorage キーを名前空間化する方式 |
| せってい：クラウドの場所 | #233 段階1 | doc ID を推測不能なランダム値（がぞくコード）へ移す。親ゲート内の明示操作 |

いずれも**子の誤操作を防ぐ簡単な計算ゲート**（親ゲート）の内側に置く（せってい系）。

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| データ保存 | localStorage を主、Firebase Firestore へクラウド同期（複数端末で共有）。スキーマはバージョン管理しマイグレーション可能（→ [data-model.md](./data-model.md)） |
| 起動速度（ローカルファースト・#142） | 起動時は localStorage を即読み込みホームを同期描画し、クラウド同期はアイドル時間まで遅延して完全にバックグラウンドで実行（朝の忙しい時間でも一瞬で記録を開始できる）。初回取り込みは同期完了前のローカル記録を消さないようローカル優先でマージする |
| オフライン / PWA | manifest + Service Worker でオフライン動作・ホーム画面追加に対応。クラウドSDKは動的読み込みで、取得失敗時もローカルのみで起動できる |
| UI方針 | 5歳でも読めるよう**ひらがな主体**。タップ操作中心の大きなボタン |
| サウンド | Web Audio API（効果音）＋録音サンプル（鳴き声）。端末ローカル設定でON/OFF。省電力のためアイドル時・タブ非アクティブ時は AudioContext を自動 suspend（#146） |
| 軽量性（重くしない・#147） | 配信アセット（HTML/CSS/JS）の gzip サイズに**パフォーマンス予算**を設け、CI（`perf-budget:check`）で超過を検知して失敗させる。予算は `scripts/perf-budget.mjs` の `BUDGETS_KIB`。画像・音声は予算判定の対象外だがレポートには出す（→ [features.md](./features.md) の「アセット総量」） |
| プライバシー / 計測 | Sentry・PostHog は鍵未設定なら無効（no-op）。送るのは操作種別と頻度のみで、**曲名・こども名等の内容は送らない** |
| クラウド保存先の保護（#233 段階1） | Firebase config は公開情報のため、**doc ID が固定・推測可能だと認証なしでは第三者が到達できる**。doc ID を初回生成のランダム値にして推測不能化する。**本命の匿名認証＋セキュリティルールは段階2**（匿名UIDは端末ごとに異なり複数端末共有と両立しないため別途設計。ルールは間借り元 `dtask-d08b6` のコンソール管理） |
| 受容しているリスク：クラウド doc は**書き込みも防げない**（→ #258） | 段階1が塞ぐのは「推測して**到達**される」ことだけで、doc ID を知られた場合の**改ざん・破壊は防げない**（認証が無いため書き込み権限を絞れない）。家庭内ツール前提で段階2まで受容する。ただしアプリ側は state を信頼せず、①**壊れたデータを渡されても起動不能にならない**（`normalizeState` の型矯正・#272）②**innerHTML へ載せる前に必ずエスケープする**（[js/html.js](../js/html.js) `escapeHtml`・#274）を必須とする |
| 品質保証 | 純粋ロジックは単体テスト（Vitest）、主要フローはE2E（Playwright）で担保。CI通過後に Vercel デプロイ |
| アクセシビリティ（#151） | `prefers-reduced-motion` で演出を停止。ダークモード対応（じどう／あかるい／よる） |

## 5. スコープ外（現状）

- 複数の子供プロフィール対応 / 認証 / ユーザー間共有
- 練習曲の動画検索（YouTube API）、天気連動ボーナス（Open-Meteo API）
- 練習リマインダー通知（PWA Push）
- 猫のスタイル切り替え（リアル系 / ほわほわ系 / ドット絵）

将来の拡張は [GitHub Issues](https://github.com/mamamakura225/claude-practice/issues)（`app/piano-pet` ラベル）で管理。初期ロードマップは [backlog.md](./backlog.md)（凍結）。

## 6. 確定事項

| 項目 | 決定内容 |
|------|---------|
| 猫の初期名 | きーちゃん |
| 猫の種別 | 3スタイルから選択（#66）: 茶トラ（既定・スコティッシュフォールド折れ耳）/ 白猫（折れ耳）/ ロシアンブルー（立ち耳グレー）。きせかえ編集モード内で切り替え |
| 効果音 | あり（Web Audio API + 録音サンプル、ON/OFF設定付き） |
| イラスト方針 | 猫本体は水彩タッチのプリレンダ透過ラスター（style×tier×mood 45枚・#167/#187/#66）。衣装も本体と画風統一のため水彩ラスター（#191 決定・#196 で SVG→ラスター移行）。**画像形式は WebP・作画枠は box×3**（#229 高解像度化＋#234 WebP化）。演出（ハート/きらきら/Zzz/エンブレム）・グラフは引き続きSVG |
