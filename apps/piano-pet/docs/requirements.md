# ピアノペット 要件定義書

> **何を・誰のために作るか（WHAT）の正本**。ふるまいの詳細は [features.md](./features.md)、データ構造と同期は [data-model.md](./data-model.md)。
> **更新ルール**: `apps/piano-pet/` のソースを変えたら、同じPRで関連docsへ反映する（[CLAUDE.md](../../../CLAUDE.md)）。

## 1. 概要・目的

5歳の子どものピアノ練習を**習慣化**するための PWA。

- 親が練習を記録し、子どもと一緒に結果を見て楽しむ
- 猫の育成・きせかえ・えさやり・バッジ・スタンプちょうで、続ける動機をつくる

## 2. 利用者と前提

| 項目 | 内容 |
|---|---|
| 親 | 練習の記録・修正、せってい（親ゲートの内側） |
| 子ども（5歳） | 猫の成長・なでなで・きせかえ・バッジ・スタンプを親と一緒に見る。スタンプを押す・アイコンを選ぶのは本人 |
| 端末 | スマートフォン中心（ホーム画面に追加する PWA）。認証なし |
| 記録の単位 | 1回 ＝ 1曲を1回弾く |
| 1日の目標 | 既定10回。親が 5〜20 で調整できる（#238） |
| コインの達成ボーナス | 目標設定に依らず **10回で固定**（#238） |

## 3. 機能要件

ふるまい・数値・実装の対応は [features.md](./features.md)（末尾に機能→実装→テストの[対応表](./features.md#トレーサビリティ表)）。

## 4. 非機能要件

### 4.1 データと同期

| 区分 | 要件 |
|---|---|
| 保存 | localStorage が主。Firebase Firestore へ同期して複数端末で共有する。スキーマはバージョン管理しマイグレーション可能（→ [data-model.md](./data-model.md)） |
| 起動速度（#142） | localStorage を同期で読んでホームを即描画する。クラウド同期はアイドル時間まで遅らせる。同期前のローカル記録を消さないよう、初回の取り込みはローカル優先でマージする |
| オフライン（PWA） | manifest＋Service Worker でオフライン動作・ホーム画面追加に対応。クラウドSDKは動的読み込みで、取れなくてもローカルだけで起動する（→ [features.md](./features.md#service-worker-のキャッシュ戦略)） |

### 4.2 セキュリティとプライバシー

| 区分 | 要件 |
|---|---|
| 計測 | Sentry・PostHog は鍵が無ければ無効。送るのは操作の種類と頻度だけで、**曲名・こども名・ごほうびの文字・レッスン日などの内容は送らない** |
| クラウド保存先の保護（#233 段階1） | Firebase config は公開情報なので、doc ID が固定・推測可能だと第三者が到達できる。doc ID を初回生成のランダム値にして推測できなくする。**本命の匿名認証＋セキュリティルールは段階2**（#258。匿名 UID は端末ごとに違い複数端末の共有と両立しないため別に設計する。ルールは間借り元 `dtask-d08b6` のコンソールで管理・→ [data-model.md 7章](./data-model.md#7-がぞくコードdoc-id-の推測不能化233-段階1)） |

#### 受容しているリスク（#258）

- 段階1が塞ぐのは「推測して**到達**される」ことだけ。doc ID を知られたときの**改ざん・破壊は防げない**（認証が無く書き込み権限を絞れない）。家庭内ツールとして段階2まで受容する
- そのかわり、アプリは state を信頼しない。次の2つを必須とする
  1. **壊れたデータを渡されても起動不能にならない**（`normalizeState` の型矯正・#272）
  2. **innerHTML へ載せる前に必ずエスケープする**（[js/html.js](../js/html.js) `escapeHtml`・#274）

### 4.3 体験と品質

| 区分 | 要件 |
|---|---|
| 表記（#359） | 子どもが読む表示は**ひらがな主体**。漢字を残すのは親向けの表記（カレンダーの曜日・日付の「年月日」）だけ。語の途中で改行しない |
| 見やすさ | 文字は背景に対して AA のコントラスト（#359）。子どもが触るボタンは 44px 以上（#397） |
| アクセシビリティ（#151） | `prefers-reduced-motion` で飾りの動きを止める。ダークモード（じどう／あかるい／よる） |
| サウンド（#146） | Web Audio API（効果音）＋録音サンプル（鳴き声）。ON/OFF は端末ごと。使っていない間は AudioContext を自動で止める |
| 軽量性（#147 #284） | HTML/CSS/JS の gzip サイズに**予算**を設け、CI（`perf-budget:check`）で超過を落とす。起動をブロックする JS と遅延読込の JS は分けて測り、厳しい上限は前者に掛ける。押されるまで要らない機能は動的 import にする（詳細と実測は [features.md](./features.md#アセット総量とパフォーマンス予算)） |
| 品質保証 | 純粋ロジックは単体テスト（Vitest）、主要フローは E2E（Playwright）。CI 通過後に Vercel へデプロイ（→ [features.md](./features.md#テストの方針とカバレッジ)） |

## 5. スコープ外（現状）

- 複数の子どものプロフィール／認証／ユーザー間共有
- 練習曲の動画検索（YouTube API）、天気連動ボーナス（Open-Meteo API）
- 練習リマインダー通知（PWA Push）
- 猫の画風の切り替え（リアル系／ほわほわ系／ドット絵）。※毛色の3スタイル（#66）は実装済み

今後の拡張は [GitHub Issues](https://github.com/mamamakura225/claude-practice/issues)（`app/piano-pet` ラベル）で管理する。初期ロードマップは [backlog.md](./backlog.md)（凍結）。
