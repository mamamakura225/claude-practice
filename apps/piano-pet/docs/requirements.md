## 概要

5歳の子供のピアノ練習を習慣化するためのPWAアプリ。
親が練習記録を入力し、子供と一緒に結果を見て楽しむ。
猫キャラクターの育成・きせかえ・えさやり・バッジ収集によるゲーミフィケーションで練習を継続させる。

---

## ユーザー

| ユーザー | 役割 |
|----------|------|
| 親 | 練習記録の入力・編集 |
| 子供（5歳） | 猫の成長・なでなで・きせかえ・バッジを親と一緒に確認・楽しむ |

UI文言はすべて**ひらがな主体**（5歳でも読める表記）で統一する。

---

## 練習の記録単位

- **1回** = 1曲（または曲の一部）を1回弾くこと
- **1日の目標** = 10回以上（`DAILY_GOAL = 10`）
- 記録例：「きらきら星 × 5回、ちょうちょ × 5回」= 合計10回
- 記録は親がアプリに入力する

## 画面構成

ハッシュベースのSPA。画面下部のボトムナビ（**ホーム / きろく / ショップ / バッジ** の4タブ）で切り替える。
練習記録入力（record）はナビには出さず、ホームのボタンから開く（ナビ上はホームを選択状態に保つ）。

### 画面1：ホーム

子供と一緒に見るメイン画面。

**表示要素**
- 猫のSVGイラスト（大きく・中央に表示、`aria-live="polite"`）
- 猫の名前（初期値「きーちゃん」）
- **なでなでボタン**（猫本体タップでも可。後述の猫インタラクション）
- **きょうの もくひょう**：今日の合計回数 `○ / 10 かい` + 進捗バー + メッセージ（達成で「もくひょう たっせい！🎉」）
- レベル + 経験値バー（XPバー）：「あと○かい で レベルアップ」
- ステータスカード4枚：🪙コイン / 🔥れんぞく日 / 🎫おやすみ券 / 💖なかよし
- 「れんしゅうを きろくする」ボタン（記録画面へ）
- ヘッダー右に **サウンドON/OFFトグル**（🔊 / 🔇）

**猫のアニメーション（mood）**
- `idle`（通常）：ゆっくり呼吸・尻尾を振る
- `happy`（練習記録直後・なでた時）：ぴょんと跳ねる、ハートが飛ぶ
- `sleep`（最後の練習から2日以上経過）：目を閉じて Zzz
- `wiggle`（なでた時のランダム反応の一種）：しっぽふり

### 画面2：練習記録入力（親操作・スタンプカード方式）

タイル状の「ハンコ」を押して回数を数える、子供にも分かりやすいスタンプカードUI。

**入力要素**
- 日付（デフォルト：今日）
- **曲を えらぶ**：曲名チップ（過去の曲を「よく弾く順→新しさ」で最大8件サジェスト）
  - 新規曲入力欄（過去の全曲名を `datalist` で補完）＋「＋」追加ボタン
  - チップをタップして「いま弾く曲」を選択
- **スタンプカード**：タップするたび選択中の曲のハンコ（🐾）が1つ増える
  - 最低10マス、超過時も常に1マス余分に出して押し続けられる
  - 10マス目（目標）を強調表示
  - 「○こ / もくひょう 10こ」のカウント、「↩ ひとつ もどす」で直前を取り消し
- 「きろくする」ボタン（曲未選択時はヒント表示、合計0回は記録不可）

**記録後の動作**
1. コイン・XP・ストリーク・バッジを計算して反映（[game.js](../js/game.js) `applySession`）
2. ホーム画面に遷移し、猫が喜ぶアニメーション再生
3. 獲得コインのポップアップ表示（レベルアップ時はその旨も表示）
4. 効果音：記録完了音 →（レベルアップ時）レベルアップ音
5. お休み券で連続を守った場合はお休み券ポップアップ、新規バッジ獲得時はバッジポップアップを順に表示
6. **同じ日付に既存記録がある場合は統合して全再計算**（目標達成ボーナスの二重取りを防ぐ）

### 画面3：記録履歴（きろく）

**表示内容**
- 連続記録カード：いまの れんぞく / さいこう きろく
- 週ごとの合計回数の棒グラフ（直近8週、SVG・外部ライブラリなし）
- 記録一覧（新しい順）：日付「M月D日（曜）」・曲名・回数・合計
- 各記録に「✏️ なおす」「🗑️ けす」

**編集・削除**
- 「なおす」：記録画面に切り替え、スタンプカードへ内容を復元して編集モード
- 「けす」：確認ダイアログのうえ削除
- 編集・削除後は **sessions を唯一の正として XP・レベル・コイン・ストリーク・バッジをゼロから全再計算**（[game.js](../js/game.js) `recomputeState`）。報酬演出は出さない

### 画面4：ショップ

**ごはんを あげる（えさやり・消費型のコインの使い道）**

| アイテム | 価格 | なかよし |
|---|---|---|
| 🐟 おさかな | 10コイン | +1 |
| 🥛 ミルク | 15コイン | +1 |
| 🍰 ケーキ | 30コイン | +3 |

- 「あげる」でコインを消費し「なかよし度（affinity）」が上がる → もぐもぐポップアップ
- 消費したコインは `pet.foodSpent` に累積し、記録の編集・削除時の全再計算でも所持コインが復活しないようにする

**きせかえ アイテム（装備型）**

| アイテム | スロット | 価格 |
|---|---|---|
| 🎀 赤いリボン | neck | 50 |
| 🎗️ ちょうネクタイ | neck | 70 |
| 👒 麦わら帽子 | head | 80 |
| 🌸 おはな | head | 90 |
| ⭐ 星の首輪 | neck | 100 |
| 🧣 マフラー | neck | 120 |
| 👓 めがね | face | 130 |
| 🦸 ミニマント | back | 150 |
| 💮 はなかんむり | head | 260 |
| 👑 王冠 | head | 300 |

- 未所持：「かう」（コイン不足時は「コインが たりない」で非活性）
- 所持済み：「そうびする」/「はずす」トグル。**同一スロットは1つだけ装備可**（別アイテムを装備すると同スロットの既存装備は自動で外れる）
- 装備するとホームの猫SVGにアンカー位置で重ねて即時表示

### 画面5：バッジ

- 「○ / 5 こ ゲット！」の取得数表示
- バッジをグリッド表示（取得済みはアイコン、未取得は 🔒）

## ゲーミフィケーション設計

実装は [game.js](../js/game.js)（純粋関数群）。

### コイン獲得

| 条件 | 獲得コイン |
|------|-----------|
| 1回練習（1曲1回） | 1コイン |
| 目標達成（その記録の合計10回以上） | +5コイン |
| ストリークがちょうど3日に到達 | +10コイン |
| ストリークがちょうど7日に到達 | +30コイン |

### 経験値（XP）とレベルアップ

| 条件 | 獲得XP |
|------|--------|
| 1回練習 | 1XP |
| 目標達成（10回以上） | +3XP |

**レベルと必要累計XP**

| レベル | 必要累計XP |
|--------|-----------|
| 1 | 0 |
| 2 | 20 |
| 3 | 50 |
| 4 | 90 |
| 5 | 140 |
| 6〜 | 前レベルから +60 ずつ |

### 猫の成長段階

| レベル | ステージ | 見た目 |
|--------|---------|--------|
| 1〜5 | kitten（子猫） | 頭でっかち・もちもち・丸くコンパクト |
| 6〜15 | young（若猫） | バランスの良い体型 |
| 16〜 | adult（成猫） | どっしりした風格 |

### ストリーク（連続練習）とお休み券

- 前日に練習していれば連続。同日の二重記録はストリークを増やさない
- **お休み券（freezes）**：ストリークがちょうど3日、および7日ごと（7・14・21…）に到達したとき +1枚付与（**上限2枚**、`MAX_FREEZES`）
- 練習に間が空いたとき、抜けた日数ぶんのお休み券があれば消費して連続を維持（救済できなければ1からリセット）
- お休み券で連続を守ったときは専用ポップアップで通知

### バッジ（実績）

| バッジ | id | 条件 |
|---|---|---|
| 🌱 はじめての れんしゅう | `first_practice` | 初回記録 |
| 🔥 れんぞく 3にち | `streak_3` | 連続3日（current/best いずれか） |
| ⭐ れんぞく 7にち | `streak_7` | 連続7日 |
| 💯 100かい チャレンジ | `challenge_100` | 累計100回 |
| 🏆 1かげつ がんばった | `month_30` | 記録した日が30日以上 |

> バッジは sessions から再判定するため、編集・削除で資格を失えば剥がれる。

## 猫のインタラクション・サウンド

### なでなで（猫タップ / なでなでボタン）

- 記録には影響しない安全な操作
- 鳴き声を再生（基本は「ニャー」、約15%の確率で「シャー」＝威嚇）
- 威嚇でなければ喜ぶ／しっぽふりの反応アニメ（ランダム）。**威嚇のときは演出を出さない**

### サウンド（[sound.js](../js/sound.js)）

- **効果音（シンセ）**：Web Audio API で生成。コイン獲得 / レベルアップ / 記録完了 / アイテム購入 / ハンコ
- **鳴き声（録音サンプル）**：なでた時のみ。`meow1〜3.mp3`（通常）、`hiss1.mp3`（威嚇）
- ヘッダーのトグルでON/OFF（設定は端末ローカル `settings.soundOn`、クラウド非同期）
- AudioContext はユーザー操作後に解錠（ブラウザの自動再生ポリシー対策）

## データ保存

- **ローカル**：localStorage の単一キー `piano-pet`（スキーマバージョン付き・マイグレーション対応）
- **クラウド**：Firebase Firestore に同期（dtask の `dtask-d08b6` プロジェクトを共有、`pianopet/data`）
  - 認証なし・Firestoreルールでアクセス制御。SDKは動的importで読み込み、オフライン時はローカルのみで動作
  - 起動時にクラウドを正本として取り込み、以降は他端末の変更をリアルタイム反映。書き込みはデバウンス
  - 同期対象は `pet / inventory / streak / badges / sessions`。`settings`・`version` は端末ローカル

> スキーマ・正規化・マイグレーション・クラウド射影の詳細は [data-model.md](./data-model.md) を参照。

## 技術スタック

| 項目 | 技術 |
|------|------|
| フロント | Vanilla JS（ES Modules・ビルドツールなし） |
| スタイリング | CSS（アニメーション含む） |
| 猫イラスト・アイテム | SVG（コードで動的生成・[cat.js](../js/cat.js)） |
| データ保存 | localStorage + Firebase Firestore（クラウド同期） |
| PWA対応 | manifest.json + Service Worker（`npm run gen-sw` でキャッシュ版を同期） |
| サウンド | Web Audio API（効果音）+ 録音mp3（鳴き声） |
| グラフ | SVG（棒グラフ・外部ライブラリなし） |
| エラー監視 / 利用計測 | Sentry / PostHog（鍵未設定なら no-op。曲名等の内容は送信しない） |

監視・外部サービスの全体方針は [docs/external-services.md](../../../docs/external-services.md) を参照。

## 確定事項

| 項目 | 決定内容 |
|------|---------|
| 猫の初期名 | きーちゃん |
| 猫の種別 | スコティッシュフォールド・茶トラ（折れ耳・丸顔・横長/前足なしのちびキャラ） |
