# ピアノペット 要件定義書

> **更新ルール**: `apps/piano-pet/` のソースを変更したら、本書と設計・機能ドキュメント（[features.md](./features.md) / [data-model.md](./data-model.md)）へ必ず反映する。詳細は [CLAUDE.md](../../../CLAUDE.md) の「ドキュメント更新ルール」を参照。
> 本書は「**何を・誰のために作るか（WHAT）**」を要件レベルで記述する。画面・報酬の具体仕様（HOW/詳細）は [features.md](./features.md)、データ構造は [data-model.md](./data-model.md) に委譲する。

## 1. 概要・目的

5歳の子供のピアノ練習を**習慣化**するためのPWAアプリ。親が練習記録を入力し、子供と一緒に結果を見て楽しむ。猫キャラクターの育成・きせかえ・えさやり・バッジ収集によるゲーミフィケーションで継続を促す。

## 2. ターゲットユーザー・利用形態

| 項目 | 内容 |
|---|---|
| 親 | 練習記録の入力・編集を行う |
| 子供（5歳） | 猫の成長・なでなで・きせかえ・バッジを親と一緒に確認して楽しむ |
| 端末 | スマートフォン中心（PWAでホーム画面に追加）。認証なし |
| 記録単位 | 「1回 = 1曲を1回弾く」。**1日の目標は10回以上** |

## 3. 機能要件

要件レベルの一覧。各機能の詳細仕様・数値・コード参照は [features.md](./features.md)。

- **初回オンボーディング（#141）**：初回起動時に、猫の吹き出し3画面の紙芝居で「①練習を記録 → ②ごほうび（コイン／猫が育つ）→ ③きせかえ・ごはん」を案内し、何をするアプリかを一目で伝えて初期離脱を防ぐ。スキップ可・一度見たら出さない（端末ローカルのフラグのみで制御）。新規アセットは持たず既存の猫SVGを流用する軽量実装
- **ホーム**：猫の表示（レベル連動・mood）、今日の目標進捗、レベル/XP・コイン・連続日数・お休み券・なかよし度の表示
- **きょうの きょく（宿題ループ・#143）**：先生の宿題を親が代理登録する。親が「きょう／こんしゅう 弾く曲＋目標回数」を設定すると、ホームに大きく「きょうの きょく」カードが出て進捗を表示し、達成で特別演出（紙吹雪＋ポップアップ）を出す。「宿題が出る→弾く→褒められる」の正のフィードバックループを家庭で閉じる。設定は親ゲートの内側（⚙️）に置き、MVPは単一曲の手入力。達成判定は既存の練習記録（`sessions`）から導出する
- **練習記録**：2つの入力方式を切替可能。①**スタンプモード**＝曲の選定は親、回数のスタンプ（🐾）は子が押す役割分担をUIで明示。②**まとめモード**＝親がその場で押せなかった日を後から曲×回数でまとめて入力。いずれも記録でコイン・XP・ストリーク・バッジを更新し、ホームで演出（同日既存記録は統合して再計算）。曲名は決定的ハッシュで色を割り当て、スタンプや曲チップに反映する（保存不要・どの端末でも同じ曲は同じ色）
- **記録履歴**：記録の一覧表示・週次の練習量グラフ・連続記録の確認、記録の編集と削除（削除・編集後は整合を保つよう再計算）。**曲別コレクション**として曲ごとの累計回数を色付きで一覧表示
- **ショップ**：コインの使い道として「きせかえアイテムの購入・装備」と「えさやり（なかよし度上昇）」。なかよし度のしきい値で**なかよしレベル**が上がり、ホームの猫エンブレム・なでなで時の特別演出などのご褒美が解放される（解放状態はなかよし度から導出）
- **バッジ**：練習の積み重ねで実績を獲得・一覧表示
- **育成・報酬**：練習回数に応じたコイン/XP付与、レベルアップによる猫の成長、連続練習の維持（お休み券による救済）
- **猫とのインタラクション**：なでると鳴く・反応する（記録には影響しない）
- **サウンド**：効果音・鳴き声。ON/OFF切替可。スタンプは押すたびにドレミ…と音程が上がり、目標マスで高いド（オクターブ）に解決する（ドレミの音程感覚を養う・#139）
- **せってい（データのバックアップ/復元・#140）**：認証なし・匿名同期のため端末故障やブラウザデータ削除でデータが消えるリスクに備え、親が全データを JSON ファイルへ書き出し／読み込みできる。ホームの ⚙️ から開く「おうちのひとへ」オーバーレイ内に配置し、子の誤操作を防ぐ簡単な計算ゲートで保護する。読み込みは上書き確認＋直前データの自動退避付き

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| データ保存 | localStorage を主、Firebase Firestore へクラウド同期（複数端末で共有）。スキーマはバージョン管理しマイグレーション可能（→ [data-model.md](./data-model.md)） |
| 起動速度（ローカルファースト・#142） | 起動時は localStorage を即読み込みホームを同期描画し、クラウド同期はアイドル時間まで遅延して完全にバックグラウンドで実行（朝の忙しい時間でも一瞬で記録を開始できる）。初回取り込みは同期完了前のローカル記録を消さないようローカル優先でマージする（→ [data-model.md](./data-model.md)） |
| オフライン / PWA | manifest + Service Worker でオフライン動作・ホーム画面追加に対応。クラウドSDKは動的読み込みで、取得失敗時もローカルのみで起動できる |
| UI方針 | 5歳でも読めるよう**ひらがな主体**。タップ操作中心の大きなボタン |
| サウンド | Web Audio API（効果音）＋録音サンプル（鳴き声）。端末ローカル設定でON/OFF。省電力のためアイドル時・タブ非アクティブ時は AudioContext を自動 suspend（#146） |
| 軽量性（重くしない・#147） | 配信アセット（HTML/CSS/JS）の gzip サイズに**パフォーマンス予算**を設け、CI（`perf-budget:check`）で超過を検知して失敗させる。機能追加での肥大化を仕組みで防ぐ。予算は `scripts/perf-budget.mjs` の `BUDGETS_KIB`（→ [CLAUDE.md](../../../CLAUDE.md) CI/デプロイ） |
| プライバシー / 計測 | エラー監視（Sentry）・利用計測（PostHog）は鍵未設定なら無効（no-op）。送るのは操作種別と頻度のみで、**曲名等の内容は送らない** |
| 品質保証 | 純粋ロジックは単体テスト（Vitest）、主要フローはE2E（Playwright）で担保。CI通過後に Vercel デプロイ |

## 5. スコープ外（現状）

- 複数の子供プロフィール対応 / 認証 / ユーザー間共有
- 練習曲の動画検索（YouTube API）、天気連動ボーナス（Open-Meteo API）
- 練習リマインダー通知（PWA Push）
- 猫のスタイル切り替え（リアル系 / ほわほわ系 / ドット絵）

将来の拡張は [GitHub Issues](https://github.com/mamamakura225/claude-practice/issues)（`app/piano-pet` ラベル）で管理。初期ロードマップは [backlog.md](./backlog.md)（凍結）。

## 6. 確定事項

| 項目 | 決定内容 |
|------|---------|
| 猫の初期名 | きーちゃん |
| 猫の種別 | スコティッシュフォールド・茶トラ（折れ耳・丸顔・横長/前足なしのちびキャラ） |
| 効果音 | あり（Web Audio API + 録音サンプル、ON/OFF設定付き） |
| イラスト方針 | SVG一本。猫本体・アイテム・アニメーションすべてSVGで実装。ラスター画像は使わない |
