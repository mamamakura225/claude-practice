# ピアノペット ドキュメント

ピアノペット（ピアノ練習PWA・猫育成）の要件・設計・機能ドキュメント一覧。

| ドキュメント | 内容 |
|---|---|
| [requirements.md](./requirements.md) | 要件定義書（目的・ユーザー・機能要件・非機能要件・スコープ外・確定事項） |
| [features.md](./features.md) | 機能詳細（画面仕様・報酬ロジック・アイテム・サウンド）＋運用（SW／テスト方針／アセット予算） |
| [data-model.md](./data-model.md) | 状態スキーマ・正規化・マイグレーション・クラウド同期 |
| [backlog.md](./backlog.md) | 初期ロードマップ（凍結。以降のバックログは GitHub Issues） |

更新ルール：`apps/piano-pet/` のソースを変更したら、**同じPRで requirements.md と該当する設計・機能ドキュメントを更新する**（[CLAUDE.md](../../../CLAUDE.md)）。非自明な設計判断は該当docに `> **設計判断**:` として理由ごと残す。

書き方の指針：1文に「事実＋理由＋経緯」を詰めない。事実の列挙は表、手順は番号付きリスト、判断の根拠は `> **設計判断**` ブロックに分ける。
