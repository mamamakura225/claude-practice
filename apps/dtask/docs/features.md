# 機能（ふるまい）

画面と操作のふるまい。コードは関数名で指す（行番号は書かない）。理由は末尾の[設計判断](#設計判断)にまとめる。

## ビュー

| ビュー | ふるまい |
|---|---|
| リスト | 1列。カードに期限・優先度・プロジェクト・タグ・サブタスク進捗・ステータスを表示。ステータスは未着手＝枠線／進行中＝青／完了＝緑 |
| Kanban | 未着手・進行中・完了の3列。スマホ幅（〜767px）は横スクロールで、列幅は画面の85%（最大320px）、列単位でスナップ |
| 今日やること | 起動時は「今日」プリセット（定義は[絞り込み](#絞り込み並べ替え)）。今日分が**あって全て完了**なら達成画面（「今日のタスクは完了！」＋次の締切＝未完了で今日より後の最小の期限まで◯日。無ければ「次の締切はありません」）。元々0件なら通常の空状態 |

- ビュー形式（リスト／Kanban）は前回値を復元する。プリセットは復元しない
- 完了カードはタイトル・説明を補助色にし、打ち消し線を付ける

## タスク操作

| 操作 | 入口 |
|---|---|
| 追加 | クイック追加バー（タイトルのみ即追加）／詳細モーダル（`＋ タスク追加`・スマホは FAB） |
| 編集 | ✏️／⋮メニュー |
| 削除 | ⋮メニュー／🗑️／左スワイプ（モバイル） |
| 完了 | ✓／右スワイプ／⋮メニュー／Kanbanセレクト／Kanban D&D／詳細モーダル |
| 並べ替え | ⋮メニューの上へ・下へ／D&D（デスクトップのみ）。どちらも手動順に切り替わる |

- **⋮メニュー**：カード右端に常時表示。編集／上へ／下へ／ステータス移動／削除。キーボードは Enter で開き、↑↓で移動、Esc で閉じて⋮へ戻る。初回だけヒントのトーストを出す
- **クイック追加**：チップで「高」「今日」「明日」を付けられる（連続追加のため次も維持）。Shift+Enter で詳細モーダルへ（タイトル・チップの値を引き継ぐ）
- **今日ビューでの追加**：期限チップ未指定でも期限＝今日で追加する（入力欄のプレースホルダーと読み上げ名で明示）。詳細モーダルを新規で開くと期限に今日が入る。期限なしのタスクは、他のビューで追加するか詳細モーダルで期限を消して作る
- **見えない追加の通知**：追加したタスクが今の絞り込みで見えないときは、トーストで理由と［すべて表示］を出す（並べ替えと「完了タスクを隠す」以外を解除）
- **プロジェクト**：サイドバーで作成（名前＋色）・削除。選ぶと絞り込まれ、ヘッダーにバッジ（✕で解除）。選択中に追加したタスクはそのプロジェクトになる。削除すると所属タスクは「なし」になり、Undo で戻せる
- **サブタスク**：カード上で展開・追加・タイトル編集・チェック。0件なら「＋ サブタスク」を表示。展開状態は端末に保存

## 繰り返し

- 毎日／毎週／毎月。**未完了→完了**になったとき、どの操作で完了にしても次回分を1件作る（`spawnNextIfNeeded`）
- 完了を外して付け直しても、前回作った次回分が残っていれば作らない（`spawnedNextId`。#351 以前に完了したタスクはこれを持たないので、戻して再完了したときに1回だけ重複しうる）
- スキップ（⏭）は今回分を外して次回分を残す
- 毎月は翌月に同じ日が無ければ月末に詰め、その次は元の日に戻る（1/31 → 2/28 → 3/31。`anchorDay`）

## 絞り込み・並べ替え

実装は [utils/filter.js](../utils/filter.js)／[utils/sort.js](../utils/sort.js)。条件はすべて AND。

| 条件 | 値 |
|---|---|
| プロジェクト・優先度・ステータス | 各値。空＝すべて |
| 完了タスクを隠す | on/off |
| プリセット | 今日（今日締切＋期限切れ未完了、当日完了分も含む）／今週（今日〜6日後）／期限切れ（未完了のみ） |
| 検索 | タイトル・説明・タグの部分一致。`#タグ` はタグの完全一致 |

並べ替えは 手動／作成日（新しい順）／期限（未設定は最後）／優先度。**完了タスクは常に末尾**。

## キーボード・Undo

| キー | 動作 |
|---|---|
| `N` | クイック追加へフォーカス |
| `/` | 検索へフォーカス |
| `?` | ショートカット一覧（ヘッダーの `?` ボタンでも開く） |
| `Ctrl+Z` / `Cmd+Z` | 直近の Undo（60秒以内・最大5件、連続可） |
| `Esc` | モーダルを閉じる／入力からフォーカスを外す（常に有効） |

- 入力中・モーダル表示中は `N` `/` `?` `Ctrl+Z` を無効にする（入力中の `Ctrl+Z` はブラウザのテキスト Undo）
- `Ctrl+Z` 以外の Ctrl / Cmd / Alt 付きの押下はブラウザ標準を優先する（Shift は `?` の入力に使うので対象外）
- 削除などの直後はトーストに［元に戻す］（5秒）。トーストはホバー中・フォーカス中は消えない

## 同期表示

ヘッダーに同期状態を出す。スマホ幅はアイコンのみ（文言は読み上げ用に残す）。

| 状態 | 表示 | いつ |
|---|---|---|
| `idle` | なし | 平常時 |
| `syncing` | 同期中… | 保存を送信中 |
| `saved` | ✓ 保存済み | 保存できた（2秒で消える） |
| `pending` | ⏳ 送信待ち（接続を待っています） | 送信が10秒以上終わらない（端末はオンライン扱いだがサーバーに届かない） |
| `error` | ⚠ 保存失敗［再試行］ | 保存に失敗。回線の切断→復帰を挟んでも、未解決なら表示し直す |
| `offline` | 📵 オフライン | 端末がオフライン |
| `local` | 💾 未同期（この端末に保存中） | クラウドの最新を読めていない（起動直後から）。読めた時点でマージして同期 |

## 表示設定・アクセシビリティ

- ライト／ダーク、文字サイズ（標準／大）。どちらも端末に保存
- **キーボード**：全操作が可能（⋮メニューがドラッグ・スワイプの代わり）。モーダルを閉じると開いたボタンへフォーカスを戻す（⋮から開いた編集は、保存で再描画されても同じタスクの⋮へ）
- **ARIA**：モーダルは `role="dialog"`。状態を持つボタン（表示切替・テーマ・プロジェクト・期限プリセット・クイック追加チップ・ハンバーガー）は `aria-pressed`／`aria-expanded`。アイコンだけのボタンと、カードごとの操作ボタン（タスク名入り）に `aria-label`。装飾アイコンは `aria-hidden`
- **コントラスト**：表示中の文字はライト／ダークとも WCAG AA（4.5:1、大きい文字 3:1）。主色の文字は `--primary-text`（背景用の `--primary` と分ける）。プロジェクト色のバッジは、選ばれた色から読める文字色を算出する（[utils/color.js](../utils/color.js)。`#RRGGBB` 以外は既定色）。ライト／ダーク両方の色を CSS 変数で渡し、テーマ切替では再描画しない
- **タップ領域**：24px 以上。プロジェクト追加・削除、サブタスク開閉、Kanbanセレクト、文字サイズは 32px 以上

## 設計判断

| 判断 | 理由・不採用案 |
|---|---|
| ⋮メニューを操作の正規ルートにする (#111) | スマホはホバーが無く、ホバーで出る ✏️🗑️ に届かなかった。スワイプ・D&D は上級者向けのショートカットとして残す |
| 起動は毎回「今日」、当日完了分も含める (#33) | 起動したらまず今日やることが見える。完了分を含めるのは統計バー（X/Y 完了）と完了確認の安心感のため。達成画面の判定だけは「未完了が0」で行い、絞り込みの定義と分ける |
| 今日ビューの追加は期限＝今日 (#352) | 期限なしで追加すると即座に絞り込みで消え、追加できなかったように見えた。今日ビュー＝今日やることを足す場所（Todoist 等の Today と同じ）。黙って期限を付けないようプレースホルダーで明示。今日以外は期限を推測できないので通知と［すべて表示］で戻す。0件時の説明的な空状態は #114 |
| 繰り返しの生成を1関数に集約 (#351) | 以前は ✓ と⋮でしか作られず、Kanbanセレクト・D&D・モーダルでは作られなかった。重複防止を「完了済みフラグ」でなく次回分の実在確認にしたのは、次回分を消した後に完了し直したら作り直すべきだから |
| Kanban の列幅を画面基準で固定 (#353) | 中身の幅で伸びて長いカードで列が画面外へ広がっていた。85% は「次の列が少し見える＝横に続きがある」手がかり。不採用：タイトル省略（読めない）、縦積み（3列の関係が一覧できない） |
| スマホのヘッダーは同期表示をアイコンのみ、375px 未満はロゴを「d」だけ (#353) | 全ボタンを1段に収めるため（320〜390px で実測）。未同期はオフラインと別アイコン・別背景で区別する。不採用：2段ヘッダー（縦の表示領域が減る）、テーマ切替の移動（動線が変わる） |
| コントラストを実効色で測って AA に揃える (#354) | ダークで赤文字が 2.9:1、プロジェクト色が最低 2.8:1、完了カードの `opacity` で中の文字が約 1.9:1 だった。完了カードは `opacity` をやめて文字色で区別。プロジェクト色はユーザーが選ぶので固定値では保証できず、算出にした |
| 期限プリセットはトグルボタン (#354) | `role=tab` だったが、矢印キー操作もタブパネルも無かった |
